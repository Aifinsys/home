02. 長期熱度因子 (Google Trends)

演算邏輯

  • ➢
    GT_Level (絕對熱度)

    最近 30 天的平均搜尋量。

    \( GT\_Level = \text{mean}(Series[-30:]) \)
  • ➢
    GT_Change (變化率)

    反映趨勢是否正在加速升溫。

    \( GT\_Change = \frac{Level_{30}}{Mean(Series[-120:-30])} - 1 \)

    若 \( GT\_Change > 0 \)，視為主題熱度正向因子。

核心代碼實作

calc_trends.py
def google_trends_factor(keywords):
    # Fetch data using pytrends
    pytrends.build_payload(keywords, timeframe="today 12-m")
    gt = pytrends.interest_over_time()
    
    series = gt[keywords].mean(axis=1)
    
    # Rolling Windows
    level_30 = series.tail(30).mean()
    prev_90 = series.tail(120).head(90).mean()
    
    # Change Rate Calculation
    chg = (level_30 / prev_90 - 1) if prev_90 > 0 else 0
    
    return {"level": level_30, "change": chg}

03. 短期交易情緒 (PTT Sentiment)

Data Source
PTT Stock / Tech_Job
Metric
Term Frequency (Hits)
Signal Processing
Log1p + Z-Score

標準化情緒分數 (Z-Score)

使用 Log 轉換平滑極端值，再進行標準化，以判斷當前討論熱度是否顯著偏離平均。

\( Z_{ptt\_hits} = \frac{\ln(1 + hits) - \mu_{\ln}}{\sigma_{\ln}} \)
Signal: 若 \( Z_{ptt\_hits} > 0 \)，表示散戶/市場關注度高於常態，短期情緒升溫。
